# Artificial Intelligence and Machine Learning (AIML) Lab Assignments

This repository contains the practical assignments for the **Artificial Intelligence and Machine Learning (AIML)** subject at **MIT ADT University, Pune**. It includes implementations of search algorithms, game playing, Python libraries, data preprocessing, supervised learning, and unsupervised learning techniques using Python.

## 📚 List of Assignments

| No. | Assignment | Topics Covered |
|---|---|---|
| 1 | Breadth First Search (BFS) | Graph Traversal, Search Algorithms |
| 2 | A* Algorithm | Heuristic Search, Pathfinding |
| 3 | Tic-Tac-Toe Game | Game Playing, Artificial Intelligence |
| 4 | Machine Learning Environment Setup | Anaconda, Jupyter Notebook, Arithmetic and Statistical Calculations |
| 5 | Python Libraries | Math, NumPy, SciPy, Pandas, Matplotlib, Seaborn |
| 6 | Data Preprocessing | Missing Values, Encoding, Normalization |
| 7 | Linear Regression | Automobile Dataset, Fuel Efficiency Prediction |
| 8 | Logistic Regression | Breast Cancer Classification, Confusion Matrix, ROC Curve |
| 9 | Bayesian Classifier | Iris Dataset, Accuracy, Precision, Recall |
| 10 | Decision Tree and Random Forest | Heart Disease Prediction, Bias-Variance Tradeoff, Feature Importance |
| 11 | K-Means Clustering | Clustering, Silhouette Score, Cluster Visualization |
| 12 | Hierarchical Clustering | Iris Dataset, Dendrogram, Comparison with K-Means |

## ⚙️ Installation and Setup

1. Install [Python](https://www.python.org/) or [Anaconda](https://www.anaconda.com/download).
2. Open Anaconda Navigator and launch Jupyter Notebook, or use the Anaconda Prompt.
3. Install the required libraries:

   ```bash
   pip install numpy scipy pandas matplotlib seaborn scikit-learn jupyter
   ```

4. Clone this repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
   ```

5. Navigate to the repository folder:

   ```bash
   cd YOUR-REPOSITORY
   ```

6. Start Jupyter Notebook:

   ```bash
   jupyter notebook
   ```

7. Open the required assignment notebook or Python file and run the code.
